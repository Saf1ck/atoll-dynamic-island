Персонажи

Маленький житель пилюли

Персонаж следит глазами за курсором, моргает, танцует под музыку и засыпает, когда вас нет. Он подпрыгивает от нажатий, радуется включённым переключателям и печатает вместе с вами. Если нажать на него, покажет одну из семи эмоций.

Нейросети

Девять ассистентов и два агента

В чате прямо на острове работают ChatGPT, Claude, Gemini, DeepSeek, Grok, Perplexity, Copilot, Le Chat и Qwen. Войдите один раз, ключи API не нужны. Кнопка «Больше места» в чате освобождает место для капчи при входе.

Если вы пользуетесь Claude Code или Codex CLI, остров покажет их запросы разрешений с кнопками «Разрешить», «Запретить» и «В терминале» и сообщит, когда работа закончена.

Подключение: Настройки → ИИ-агенты → Подключить. Если остров закрыт, агент спросит в терминале, как обычно.

Приватность

Ничего не собирает. Телеметрии нет.

Сеть нужна только функциям, которые вы видите. Распознавание текста, QR-коды, запись экрана и буфер обмена работают на вашем компьютере. Пароли из менеджеров паролей в историю буфера не попадают.

Требования

  • Windows 10 (версия 2004 и новее) или Windows 11, 64 бита
  • Microsoft Edge WebView2 Runtime для страницы «Чат». В Windows 11 он уже есть
  • Visual C++ Redistributable 2015–2022 (x64) для записи экрана
  • .NET ставить не нужно, всё уже внутри

Обновление и удаление

  • Остров сам сообщит о новой версии, обновление в один клик. Настройки сохраняются
  • Проверка обновлений: Настройки → Поведение → Обновления
  • Удаление за 10 секунд: Настройки → Поведение → «Удалить Atoll» или через «Установленные приложения» в Windows
  • Интерфейс на семи языках: русский, английский, украинский, испанский, немецкий, португальский и китайский
